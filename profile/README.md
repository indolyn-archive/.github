# indolyn-archive

这里是 `indolyn-archive`，我的个人组织仓库集合。

组织所有者是 [Microindole](https://github.com/Microindole)。这里主要存放课程项目、实验内容和一些已经完成的练习项目。大多数仓库都会在完成后归档，所以你看到的内容通常都是“结题版本”。

部分仓库是几位同学一起完成的，既感谢这群作者的投入，也把这些项目当成团队努力的结晶保存下来。

## 这里会放什么

- 课程作业
- 实验项目
- 已完成的练习仓库
- 其他适合归档保存的内容
